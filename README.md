## 🎨 快速配置图片的4种方法

### 方法1️⃣：使用配置工具（最简单）
1. 打开 http://localhost:8888/setup.html
2. 输入4张图片的URL
3. 点击"生成配置代码"
4. 复制代码，粘贴到 index.html

### 方法2️⃣：本地图片（推荐）
```bash
# 1. 在项目文件夹创建 images 文件夹
mkdir C:\Users\lvminghe\zhenhuantest\images

# 2. 放入4张竖版美图：
#    - zhenhuang.jpg (甄嬛)
#    - huafei.jpg (华妃)
#    - huanghou.jpg (皇后)
#    - shenmeizhang.jpg (沈眉庄)

# 3. 在 index.html 中修改图片URL为：
#    image: "./images/zhenhuang.jpg"
```

### 方法3️⃣：网络图片
直接用任何公开的图片URL，例如：
```javascript
image: "https://example.com/zhenhuang.jpg"
```

### 方法4️⃣：小红书链接
从小红书下载高清美图，上传到图床（如：sm.ms, imgur.com），获取直链使用。

## 🐛 常见问题

**Q: 访问不了测试页面？**
A: 检查服务器是否运行：
```bash
curl http://localhost:8888
```

**Q: 图片显示不出来？**
A:
- 检查URL是否正确
- 确保本地文件夹结构正确
- 尝试Ctrl+F5强制刷新
- 检查浏览器控制台是否有报错

**Q: 想修改题目或角色？**
A: 编辑 `index.html` 中的 `questions` 和 `characters` 变量即可。

**Q: 分享功能不工作？**
A: 某些浏览器不支持原生分享，此时会自动降级为复制链接到剪贴板。
